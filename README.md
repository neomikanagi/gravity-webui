# GRAVITY ウェブルーム

GRAVITY（音声SNS）をブラウザで使うための**非公式** WebUI です。公式アプリのアカウントで、音声ルームの試聴／入室、投稿、プロフィール、私信ができます。公式とは無関係です。利用は自己責任で、アプリの利用規約に反する可能性があります。

単一アカウント向けです。1つのデプロイにつき1人のアカウントで使います。資格情報はこのリポジトリに含まれていません。

## できること

- **ルーム試聴**：入室せずに音声と名簿だけ見られます。
- **入室・通話**：公式アカウントで入室し、音声を受信できます。マイク席に上がって発言することもできます。退室時に自動のあいさつは送りません。
- **開室・ルーム管理**：自分のルームを作り、お知らせやタグ、マイク席の操作ができます。
- **投稿**：おすすめ／フォロー中／新着の投稿を読み、返信やいいねができます。
- **プロフィール**：他人のプロフィール、フォロー／フォロワー、ギフト履歴、足跡が見られます。
- **私信**：フレンドとの1対1チャット。テキストと画像（jpg/png/gif、1MBまで）。
- **その他**：受け取ったギフトへの自動お礼、デイリータスクや宝箱の自動受け取り（条件を満たしたものだけ）、チャットの英語翻訳（自分の DeepL キー。未設定なら無効）。

画面は日本語です。プロトコルの詳細は `docs/` にあります。

## 使い方

1. 下の手順でログインセッションを用意し、`.session/` に置きます。
2. 必要なら `.env` に `DEEPL_AUTH_KEY` を書きます（空なら翻訳は動きません。キーをリポジトリに入れないでください）。
3. `docker compose up -d --build` で起動します。既定は HTTP 8787 / HTTPS 8788（証明書は `./tls/`）。

## Mac でログイン状態を用意する

ブラウザの Cookie ではなく、公式アプリのセッショントークンを使います。Mac の公式アプリ（Apple Silicon 上の iOS 版）にログインしたあと、そのトークンをサーバーへ渡します。パケットキャプチャは不要です。

1. Mac の公式 GRAVITY アプリで普通にログインします。
2. `scripts/` を Mac にコピーし、環境変数を2つ設定します：`GRAVITY_SSH_HOST`（サーバーの SSH 別名）、`GRAVITY_REMOTE_SESSION_DIR`（サーバー側チェックアウトの `.session` の絶対パス）。
3. Mac で `bash scripts/sync_mac_session.sh` を実行します。アプリの `user.json` を読み取り専用で取り出し、SSH 経由でサーバーの `.session/www-token.json` に原子的に書き込み、セッションが有効か確認します。自動ログインはしません。プロキシも使いません。トークンを画面に出しません。
4. サーバー側には別途 `.session/ios-device.json`（署名用の端末フィールド。必要なキーは `gravity-sign-ios.cjs`）が必要です。自分のアプリから取った端末ごとの値なので、リポジトリには入っていません。
5. ほかの端末で再ログインしてトークンが無効になった場合（40025/40026）は、Mac アプリ側のログインが残っているか確認します。残っていれば手順 3 を再実行、切れていれば先にアプリでログインし直してから手順 3 です。

## テスト

```bash
node --test tests/*.test.cjs
```

全部オフラインで、合成データだけを使います。
