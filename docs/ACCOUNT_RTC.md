# 入室、試聴、接続の復旧

部屋の接続は「試聴」と「入室」の2つです。試聴は匿名で聞くだけ（登録なし、文字なし）。入室は公式アカウントで登録し、チャットと公式マイク席の権限に従って発言できます。

## 2つの接続

- **試聴**：匿名 RTC と入室不要の名簿。RTM／Enter／ハートビート／マイクはありません。名簿は `roomMemberList` と `anchorUserList` から15秒ごとに更新し、人を押すとプロフィールを見られます。匿名 006 トークンは約300秒、発行ごとに UID が違うので、新しい UID のトークンで古い UID を延長できません。期限の60秒前に次の匿名接続を作り、新しい音声が来てから古い接続を外します（最大3秒待ってエコーを避けます）。失敗時は古い音声を残して再試行し、5回失敗で停止します。部屋を変える／止めると候補接続とタイマーを捨てます。ネットワーク切替の完全な無音は約束しません。
- **入室**：RTC audience ＋ RTM ログイン／チャンネル ＋ `AudioLive_Enter`。既定では入室あいさつを送りません。サーバーは公式の interval で `AudioLive_HeartBeat` を送ります。マイク席の申請・承認・オンは独立です。退室時に登録とこのページが取った席を掃除し、別れのメッセージは送りません。

入室の「サイレント」はあいさつを送らないことだけで、名簿は見えます。旧「非表示入室」は廃止済みです。前後端は古い非表示リクエストを拒否し、黙って通常入室には変えません。サーバーは古い通常クライアントの `stealth:false` だけ互換します。Web と App は同じアカウントなので、接続が互いに置き換わることがあります。App が Web を押し出しても、Web は自動では取り戻しません。

## マイク席

1. 最初は audience、マイクオフ。ホスト／管理者は直接着席できます。承認不要の部屋は先に直接申請し、拒否されたらホストに頼みます。グループ通話 `room_type=2` は必ず先に承認リクエストを出し、オープンなグループ通話では同時に直接着席も試します。入室時はできるだけ `enterGroupRoom` も呼びます。
2. 承認リクエストは RTM `messageType=3/orderType=3` でホストへ。管理者がいればチャンネル type 14 も足します。承認 `orderType=4`、招待 `orderType=1` は Agora peer と部屋を照合します。管理名簿にホストが抜けていても `anchor_rtc_uid` を認めます。招待は 1対1 でもチャット放送でも、自動で着席しマイクはオフのままです。
3. `applyForSeat(channel_id,mute_type=1)` のあと、公式席を読み直して確認します。「マイクオン」を押したときだけ role 1 トークン、端末キャプチャ、`updateAnchorStatus` でミュート解除、host 切替と publish をします。公式側で席を失う／ミュートされるとキャプチャを閉じ、送信は自動では戻しません。SDK が受け付けても、相手が聞こえたことにはなりません。
4. `leaveForSeat` は自分の非ホスト席だけ扱います。このページが取った席は停止／タイムアウトで掃除します。引き継ぎ前からあった App の席は、このページが外したミュートだけ戻し、勝手に下ろしません。ホストは Web から「ルームを終了」できます。通常の退室では部屋を閉じません。
5. ホスト向け（Web は公式クライアントではないので、開室後も変更可）：`updateRoom` で tags／お知らせ／`auto_pass` を上書き。席から下ろすのは 1対1 の `orderType=0`。退出させるのは `AudioLive_Kick`（presence の `user_id` を書き換え）のあと RTM `messageType=4`。着席許可は `orderType=4`。聞き手の「この人をミュート」はこのページの再生だけ変えます。自動歓迎は 1対1 の TextMessage type 12。ルームの自動いいねはチャット type 13。

## 更新、ハートビート、切断

- 入室後は同源 `POST /api/member/renew`。RTC／RTM の早い期限の60秒前、SDK の期限切れ通知とまとめてリクエストします。固定の `getAgoraToken` で元の部屋／元の UID のトークンを取り、2つのインスタンスがそれぞれ `renewToken` します。再ログイン、Enter、あいさつはしません。RTC は App ID／部屋 CRC／UID CRC／権限と有効期限、RTM は App ID／ログイン宣言／有効期限を検証します。role 1 は公式席・非ミュート・このページが明示的にミュート解除したことが必要です。Enter 未確認の許可では更新しません。
- マイクオフの受信だけで、古いトークンがまだ30秒以上残っているときの一時的な HTTP／ネットワーク失敗は5秒ごとに再試行します。古いトークンの寿命は延ばしません。硬い拒否、SDK 更新失敗、マイクオン中の失敗は停止します。タイムアウト／退室／部屋替え／別端末ログインの遅れて来た結果は使いません。
- 短い RTC `RECONNECTING` では先にマイクを閉じ、SDK を待ちます。最終 `DISCONNECTED` は受信中のふりをしません。いま有効な permit で新しいトークンを取り、元の UID／部屋で音声を繋ぎ直し、RTM を更新します。RTM の再ログイン、Enter の再送、自動マイクオンはしません。一時トークンの読み取り失敗は最大5回、失敗したら明確に停止します。BAN／退出／別端末は復旧しません。
- member permit は App セッションと部屋に結び、90秒 watchdog、フロントは5秒ごとに確認します。有効状態のポーリングは permit を延ばしますが、renew 自体は watchdog を延ばしません。HTTP は30秒期限です。確認済みの閉室、失効セッション 40025／40026、アカウント変更のような硬い拒否が連続2回で停止します。ネットワーク／ハートビートの柔らかい失敗は表示を落として受信を続け、およそ2分失敗が続いたら止めます。すでに入室中の 40202 は先にプレビューを読みます。部屋名／ホストも無い＝閉室（404、硬い拒否）。プレビューが残っている＝柔らかい失敗（503）。
- Enter 成功後は公式の `interval`（秒）でハートビートします。初回の既定は60秒。応答はオブジェクトでも JSON 文字列でも構いません。ハートビートは元のアカウント、部屋、最新の席、人数、iOS バージョンを使い、Enter や文字は繰り返しません。新しい空部屋の人数 API が `errno=1` で data 空なら0人です。ほかのエラーを0人扱いしません。
- 入室は先に Enter します。拒否され、このページが一度も成功を確認していないときだけ Quit＋Enter を1回やり直します。無条件に先に Quit すると、遅れた結果が新しい Enter を上書きします。通常退出の掃除失敗は 1→60 秒のバックオフで再試行し、10回で諦めます（公式の在室はハートビート TTL で消えます）。部屋が閉じている掃除は完了とみなします。強制退出は先にローカルを切り、自分の許可を捨て、遅れるかもしれない Quit は足しません。トップバーの強制退出に部屋番号は不要です。`pagehide` では先に keepalive で release を送り、それから RTC/RTM を外します。新しい connect が残留許可に当たったらそのまま引き継ぎます。同じ部屋なら Quit を出さず（遅延が新しい Enter を潰すのを避ける）、開いているマイクだけ閉じて席を継承します。別の部屋なら先に旧部屋を掃除します（できる範囲で）。

## 名簿と出典

カタログは `ext.is_close≠0` の部屋を捨てます（ランキング API は当日終了した部屋を残し、App も終了扱いにします）。部屋情報と席確認は同じ App セッションに結びます。40202 はプレビューとフレンド一覧のどちらも部屋がオンラインだと証明できないときだけ 404 です。そうでなければ 409（入場制限）か、すでに入室中なら 503。空の部屋情報は一度だけ読み直し、まだ一致しない／席ダイジェストが通らなければ 503 で、「権限なし」とは言いません。公式 HTTPS がデータの権威です。006 宣言の解析は署名を検証しません。席 RSA は報告されたダイジェストだけ検証し、iOS payload の完全 MD5 結びは未確認です。

- `qa/C3770k0`：`getAgoraToken(channel_id,role_type)`。`Na/E0.n`、`ua/C4237C.x`：SDK の元接続 renew。
- `q9.c`／`q9.CallableC3731b`：署名 POST `/gravity/lcs/cover`、`version=1`、`AudioLive_Enter/HeartBeat/Quit`。`Ma/C1105y`、`Na/G0`、`HeartRespData`：ハートビート interval。
- `Na/E0`、`ua/C4237C`：RTM の承認、招待、文字。`qa/Z0`、`qa/j2`、`qa/Y0`：申請、ミュート、下席。
- `qa/C0`：`roomMemberList(channel_id,anchor_id,last_id)`。最大5ページ読んで重複を除きます。席の外の国は `user/userListInfo` のバッチ、6時間キャッシュ。インストール帰属 `getOrigin` は使いません。ページ分割で自分が落ちたときは、通常の現在部屋だけ、検証済みの自分の名刺を残します。それが公式名簿にまだいる証明にはしません。
- RTM 1.5.1 はローカル資産に固定し、ログアップロードを閉じます。チャット外層は `messageType=0/orderType=-1/ver=2`、内層の文字は `type=1`。公式 CDN の画像だけ表示し、Web からチャット画像は送りません。送信は自分の名刺、部屋、レート制限を照合し、12秒タイムアウトで自動再送しません。あいさつはボタンを押したときだけ。ホストが「入室歓迎」を入れると、入室した人へテンプレートの日本語歓迎を送ります。退室に別れの言葉はなく、from 自動返信もありません。
